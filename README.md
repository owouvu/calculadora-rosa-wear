# Calculadora Rosa (Wear OS)

Calculadora para reloj inteligente Wear OS hecha con Kotlin y Jetpack Compose, con diseño rosa.

- Operaciones: suma, resta, multiplicación, división, porcentaje, borrar y limpiar.
- Pantalla redonda desplazable con la corona o el dedo.

## Cómo abrirla
1. Abre la carpeta en Android Studio y espera el Gradle Sync (JDK 21).
2. Crea un emulador **Wear OS Small Round** en Device Manager.
3. Pulsa Run.
